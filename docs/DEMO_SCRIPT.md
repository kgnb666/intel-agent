# 3 分钟演示脚本

> 目标：用 3 分钟讲清「这是什么、数据怎么来、AI 怎么用、工程上有什么亮点」。
> 建议用 Xbox Game Bar / OBS 录屏，按下面的分镜逐段录制后剪辑。

## 演示前准备

- [ ] 本地跑通：`python run_daily.py --no-send` 与 `streamlit run dashboard.py`
- [ ] 准备一个**未入库的新文章场景**（或直接用「立即采集」按钮现场抓）
- [ ] 打开 `output/daily_*.html` 日报文件备用
- [ ] 若用真实 Key：确认 `LLM_API_KEY` / `EMBEDDING_API_KEY` 已配置；无 Key 时确认降级路径也能演示

## 分镜脚本

### 第 1 段：开场定位（30 秒）

> 「这是一个行业情报分析 Agent：每天自动从 36氪、IT之家、少数派抓取电商与消费行业的资讯，经过去重、LLM 分析、历史关联后，生成可视化看板和每日邮件日报。默认主题是电商，改一个配置文件就能切到任何行业。」

画面：看板主页，鼠标划过顶部指标卡（今日新增 / 库内总量 / 情感占比）。

### 第 2 段：数据实时流入（30 秒）

点击侧边栏「立即采集」→ 展示一轮抓取、关键词过滤、去重入库的过程。

话术要点：
- URL 唯一约束 + 标题相似度 ≥0.85 双重去重
- 增量入库：同一链接绝不重复

### 第 3 段：LLM 结构化分析（40 秒）

切到情报列表，点开一条 AI 摘要，展示**摘要 / 情感 / 标签 / 关键实体**四项结构化输出。

话术要点：
- prompt 字段契约 + JSON 强制 + 失败重试，不把 LLM 当确定性函数
- token 用量入库，单次上限 `max_per_run=20`，成本可控

### 第 4 段：RAG 历史关联（40 秒）

切到对话式问答 Tab，问「这周拼多多有什么动态」→ 展示带引用的回答。

话术要点（面试重点）：
- 为什么用向量检索：语义相似 ≠ 字面相似（"财报超预期" vs "买菜盈利改善"）
- 为什么不上向量数据库：百级数据 numpy 毫秒级，BLOB 存 SQLite，避免过度工程
- 无 Key 时自动降级关键词检索，不崩

### 第 5 段：邮件日报（30 秒）

打开 `output/daily_2026-08-24.html`（或已收到的邮件），展示 HTML 日报结构。

话术要点：每步独立容错，某环节失败把"降级说明"写进当天邮件，半成品日报好过没有日报。

### 第 6 段：收尾（30 秒）

回到架构图（README 或 docs/ARCHITECTURE.md），30 秒串完整条链路，强调三个工程决策：
1. 数据源选 RSS 而不是硬爬（稳定、无反爬）
2. 双重去重以"事件"为粒度
3. 所有模块支持 dry-run / 降级，工程系统假设依赖会挂
